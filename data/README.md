# Data directory

No third-party Pakistan geospatial data are redistributed in this repository.

- `templates/real_road_segments_template.csv` is an empty schema template for future observed road-link data.
- The CLI can generate `synthetic_segments.csv` for reproducibility tests. Generated rows must remain labelled as synthetic.
- The candidate real datasets and access notes are listed in `../docs/SOURCES.md`.

Do not place raw OSM, satellite, DEM, population or facility datasets in a public repository until the exact source licence and redistribution conditions have been checked.
